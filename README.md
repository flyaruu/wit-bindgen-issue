## Issue exporting components from a different crate
Ended up asking in the wasmCloud Slack channel:

Me:

It was all smooth sailing until I tried to export a component from another crate. I found a switch on the wit_bindgen::generate macro called ‘pub_export_macro’ that _should_ make that macro public so it is accessible from other crates. If I use the macro the call doesn’t give an error, but the generation definition itself. Any ideas? I've tried chatgpt, but we end up going in circles.
